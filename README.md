# GitHub Knowledge Assistant

An AI-powered GitHub Repository Analyzer built with Next.js and GitHub API.

## Features

- Analyze any public GitHub repository
- View repository details
- Display Stars, Forks, Issues
- Show Repository Language
- Display Owner Avatar
- Repository Description Viewer
- Modern Responsive UI

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- GitHub REST API

## Installation

```bash
git clone https://github.com/utsavaraj/GitHub_Knowledge_Assistant.git
cd GitHub_Knowledge_Assistant
npm install
npm run dev
```

## Usage

1. Enter a GitHub repository URL
2. Click Analyze Repository
3. View repository information instantly
